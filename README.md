# HR Analytics Dashboard - Attrition Analysis

An interactive Power BI dashboard that analyzes employee attrition,
built as part of my Data Analytics internship.

![Dashboard](dashboard.png)

## Key Insights
- 1,472 employees analyzed, 238 left (16.17% attrition rate)
- Employees earning up to 5K had the highest attrition
- The 26-35 age group left the most
- Laboratory Technicians had the most exits of any job role (62)
- Single employees made up about half of all attrition

## What I Did
- Cleaned and prepared the data in Power Query
- Created DAX measures for attrition count and attrition rate
- Built KPI cards, charts, and a job role matrix
- Added slicers for age group, travel, department, and education

## Tools
Power BI, Power Query, DAX
